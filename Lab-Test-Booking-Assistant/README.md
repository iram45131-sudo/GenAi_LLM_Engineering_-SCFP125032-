# Lab Test Booking Assistant

## Project Overview
An AI-powered Lab Test Booking Assistant that helps users
view laboratory tests, check available slots, book tests,
view their bookings, and cancel appointments.

## Technologies Used
- Python
- SQLite
- LangChain
- LangGraph
- Groq LLM
- DuckDuckGo Search
- Kaggle Notebook

## Features
- View available laboratory tests
- Check appointment slots
- Book laboratory tests with user approval
- View personal bookings
- Cancel bookings with user approval
- User-specific booking isolation
- Email redaction for privacy
- General test information through web search
- Evaluation using predefined test scenarios

## How to Run
1. Open the notebook in Kaggle.
2. Add your Groq API key in Kaggle Secrets.
3. Run all notebook cells from top to bottom.
4. Interact with the assistant through the chat interface.

## Database
SQLite database with three tables:
- tests
- slots
- bookings
